## 项目概述

本项目是一个将 Apache ECharts 官方文档转换为 Vario-Vue Schema 的完整解决方案。

### 核心功能

1. **数据获取** (`packages/fetcher`) - 从 ECharts 官网获取物料数据
2. **数据转换** (`packages/core`) - 将原始数据转换为 Vario-Vue Schema
3. **智能组件** (`packages/smart-components`) - 提供智能表单组件
4. **命令行工具** (`packages/cli`) - 提供 CLI 命令
5. **可视化控制台** (`apps/studio`) - 提供 Web 界面管理

### 技术栈

- **语言**: TypeScript
- **运行时**: Node.js 18+
- **包管理**: pnpm
- **构建工具**: TypeScript Compiler / Vite
- **前端框架**: Vue 3 + Element Plus
- **状态管理**: Pinia
- **UI 设计**: 遵循 web-design-spec 规范

## 主要特性

### 1. 数据获取

- ✅ 从 ECharts 官网自动获取数据
- ✅ 并发控制（默认 6 并发）

## 快速开始

### 安装

```bash
# 克隆项目
git clone <repo-url>
cd vario-vue-echarts

# 安装依赖
pnpm install

# 构建核心包
pnpm build:core
```

### CLI 使用

```bash
# 获取基础数据
pnpm cli fetch

# 获取所有选项详情
pnpm cli fetch --all

# 强制更新
pnpm cli fetch --force

# 检查更新
pnpm cli check-update
```

### 程序化 API

```typescript
import { EChartsFetcher } from '@vario-echarts/fetcher';

const fetcher = new EChartsFetcher();

// 获取基础数据
const baseData = await fetcher.fetchBaseData();

// 批量获取选项
for await (const result of fetcher.fetchOptionsBatch(['title', 'legend'])) {
  console.log(result.key);
}

// 保存到 base 目录
await fetcher.saveToBase('./data/base');
```

### 启动 Studio

```bash
# 开发模式
pnpm dev:studio

# 构建
pnpm build:studio
```
