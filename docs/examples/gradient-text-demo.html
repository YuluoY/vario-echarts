💡 实现原理

ECharts 中的文字渐变需要使用对象格式，而不是 CSS 字符串：

❌ 错误用法（不生效）

textStyle: {
  color: 'linear-gradient(90deg, #ff0000 0%, #0000ff 100%)'  // CSS 格式不支持
}

✅ 正确用法（ECharts 格式）

textStyle: {
  color: {
    type: 'linear',
    x: 0, y: 0, x2: 1, y2: 0,  // 从左到右
    colorStops: [
      { offset: 0, color: '#ff0000' },
      { offset: 1, color: '#0000ff' }
    ]
  }
}

🛠️ 使用转换工具

import { toEChartsColor } from '@vario-echarts/smart-components';

// 自动转换 CSS 渐变为 ECharts 格式
const echartsColor = toEChartsColor('linear-gradient(90deg, #ff0000 0%, #0000ff 100%)');
