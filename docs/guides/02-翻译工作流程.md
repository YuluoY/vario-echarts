# 翻译系统使用指南

## 概述

本项目集成了基于 DeepSeek API 的自动翻译系统，在转换 ECharts 配置时自动将所有英文字段名翻译为中文。

## 工作原理

1. **字段收集**：在第一遍遍历 Schema 时，收集所有 `placeholder` 和 `ElCollapseItem.title` 字段
2. **批量翻译**：调用 DeepSeek API，每批翻译 50 个字段
3. **词表保存**：将翻译结果保存到 `data/translations.json`
4. **应用翻译**：在第二遍生成 Schema 时，将中文标签应用到输出

## 使用方法

### 启用翻译

```bash
# 转换时启用翻译
pnpm convert --translate

# 指定 API Key（默认已配置）
pnpm convert --translate --api-key sk-xxx

# 只转换特定选项并翻译
pnpm convert --keys title legend --translate
```

### 不启用翻译

```bash
# 默认不翻译，使用驼峰命名作为 fallback
pnpm convert

# 已有词表时也不会应用翻译
pnpm convert --keys tooltip
```

## 词表管理

### 词表位置

- **路径**：`data/translations.json`
- **格式**：
  ```json
  {
    "title": "标题",
    "show": "显示",
    "color": "颜色"
  }
  ```

### 手动编辑词表

您可以直接编辑 `data/translations.json` 来调整翻译：

```json
{
  "backgroundColor": "背景色",  // 改为更简洁的翻译
  "customField": "自定义字段"    // 添加新字段
}
```

### 增量翻译

词表支持增量更新：
- 已翻译的字段不会重复调用 API
- 只翻译新增的字段
- 保留手动编辑的内容

## 翻译质量

DeepSeek API 针对 ECharts 术语进行了优化，能够：

- **准确翻译**：专业术语如 `visualMap` → `视觉映射`
- **简洁表达**：`textBorderColor` → `文本边框颜色`
- **一致性**：相同后缀使用相同翻译（如 `Color` 统一为 `颜色`）

当前词表包含 **692 条翻译**。

## 配置选项

### CLI 参数

```bash
--translate              # 启用自动翻译
--api-key <key>          # DeepSeek API Key（默认：sk-94cb9fae48e242a4a7fe4d83fa291767）
```

### 环境变量

```bash
# 设置 API Key
export DEEPSEEK_API_KEY=sk-xxx
pnpm convert --translate
```

## 故障排除

### API 调用失败

如果 DeepSeek API 调用失败，系统会：
1. 打印错误信息
2. 使用驼峰命名转空格作为 fallback
3. 继续完成转换

### 词表损坏

如果词表文件损坏，删除后重新生成：

```bash
rm data/translations.json
pnpm convert --translate
```

### 离线使用

不启用 `--translate` 时，系统使用简单的驼峰命名转换：
- `backgroundColor` → `background Color`
- `textStyle` → `text Style`

## 技术实现

### FieldTranslator 类

```typescript
import { FieldTranslator } from './translator.js';

// 创建翻译器
const translator = new FieldTranslator(
  'data/translations.json',  // 词表路径
  'sk-xxx'                    // API Key
);

// 收集字段
translator.collectField('title');
translator.collectField('show');

// 批量翻译
await translator.translatePending();

// 保存词表
translator.saveDict();

// 获取翻译
const zh = translator.translate('title'); // "标题"
```

### 集成到转换流程

1. **收集阶段**：遍历所有 Schema 节点，收集字段名
2. **翻译阶段**：调用 `translatePending()` 批量翻译
3. **应用阶段**：在生成 Schema 时替换 placeholder 和 title

## 最佳实践

1. **首次转换**：使用 `--translate` 生成完整词表
2. **日常开发**：不使用 `--translate` 加快转换速度
3. **发布前**：使用 `--translate` 确保所有新字段都已翻译
4. **定期检查**：人工校对 `data/translations.json` 中的翻译质量
