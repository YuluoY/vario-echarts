# 国际化文件使用指南

## 概述

翻译系统会自动生成中英文国际化文件，方便在不同场景下使用。

## 文件结构

```
data/
├── translations.json     # 原始翻译词表（中文）
└── i18n/
    ├── zh-CN.json       # 中文国际化文件
    └── en-US.json       # 英文国际化文件
```

## 自动生成

运行转换命令时自动生成：

```bash
pnpm convert --translate
```

输出：
```
💾 词表已保存: data/translations.json
📊 共 692 条翻译
🌐 国际化文件已生成:
   - data/i18n/zh-CN.json
   - data/i18n/en-US.json
```

## 使用方法

### 在 Vue 应用中使用

```typescript
import zhCN from '@/data/i18n/zh-CN.json';
import enUS from '@/data/i18n/en-US.json';

const i18n = {
  'zh-CN': zhCN,
  'en-US': enUS
};

// 获取翻译
const locale = 'zh-CN';
const label = i18n[locale]['title']; // "标题"
```

### 与 vue-i18n 集成

```typescript
import { createI18n } from 'vue-i18n';
import zhCN from '@/data/i18n/zh-CN.json';
import enUS from '@/data/i18n/en-US.json';

const i18n = createI18n({
  locale: 'zh-CN',
  messages: {
    'zh-CN': {
      fields: zhCN
    },
    'en-US': {
      fields: enUS
    }
  }
});

// 在组件中使用
const { t } = useI18n();
const label = t('fields.title'); // "标题" or "Title"
```

### 在 Schema 中动态切换

```typescript
import zhCN from '@/data/i18n/zh-CN.json';
import enUS from '@/data/i18n/en-US.json';

function getFieldLabel(field: string, locale: string = 'zh-CN') {
  const i18n = locale === 'zh-CN' ? zhCN : enUS;
  return i18n[field] || field;
}

// 使用
const label = getFieldLabel('title', 'zh-CN'); // "标题"
const labelEn = getFieldLabel('title', 'en-US'); // "Title"
```

## 翻译质量

### 中文翻译特点

- ✅ **准确性**：符合 ECharts 配置项实际含义
- ✅ **简洁性**：一般 2-4 个汉字
- ✅ **专业性**：使用图表领域术语
- ✅ **一致性**：相同后缀统一翻译

示例：
```json
{
  "color": "颜色",
  "textColor": "文本颜色",
  "backgroundColor": "背景颜色",
  "borderColor": "边框颜色"
}
```

### 英文翻译特点

- ✅ **可读性**：驼峰命名转空格分隔
- ✅ **首字母大写**：符合英文标题规范
- ✅ **保持语义**：与原字段名一致

示例：
```json
{
  "backgroundColor": "Background Color",
  "textBorderWidth": "Text Border Width",
  "shadowOffsetX": "Shadow Offset X"
}
```

## 更新流程

1. **修改词表**：手动编辑 `data/translations.json`
2. **重新生成**：运行 `pnpm convert --keys <option> --translate`
3. **自动同步**：i18n 文件自动更新

## 最佳实践

### 1. 使用类型安全

```typescript
import zhCN from '@/data/i18n/zh-CN.json';

type FieldKey = keyof typeof zhCN;

function getLabel(key: FieldKey, locale: string = 'zh-CN'): string {
  // TypeScript 会检查 key 是否存在
  return locale === 'zh-CN' ? zhCN[key] : enUS[key];
}
```

### 2. 提供 fallback

```typescript
function getLabel(key: string, locale: string = 'zh-CN'): string {
  const i18n = locale === 'zh-CN' ? zhCN : enUS;
  return i18n[key] || key; // 找不到时返回原值
}
```

### 3. 支持嵌套路径

```typescript
function getNestedLabel(path: string, locale: string = 'zh-CN'): string {
  const keys = path.split('.');
  const i18n = locale === 'zh-CN' ? zhCN : enUS;
  
  return keys.reduce((acc, key) => {
    return acc?.[key] || key;
  }, i18n as any);
}

// 使用
getNestedLabel('title.textStyle.color', 'zh-CN');
// 先查找 title → textStyle → color
// 找不到则返回 "color"
```

## 扩展其他语言

需要支持其他语言时，可以基于 en-US.json 翻译：

```bash
# 1. 复制英文文件
cp data/i18n/en-US.json data/i18n/ja-JP.json

# 2. 手动翻译或使用翻译工具
# 修改 ja-JP.json 中的值为日文

# 3. 在应用中使用
import jaJP from '@/data/i18n/ja-JP.json';
```

## 常见问题

### Q: 国际化文件没有生成？

A: 确保使用了 `--translate` 选项：
```bash
pnpm convert --translate
```

### Q: 如何只更新国际化文件？

A: 重新运行转换命令即可，不会重复调用 API：
```bash
pnpm convert --keys title --translate
```

### Q: 可以手动编辑国际化文件吗？

A: 建议编辑 `data/translations.json`，然后重新生成 i18n 文件。直接编辑 i18n 文件会在下次转换时被覆盖。

### Q: 如何批量导出为 Excel？

A: 可以使用脚本转换：

```javascript
import zhCN from './data/i18n/zh-CN.json';
import enUS from './data/i18n/en-US.json';
import XLSX from 'xlsx';

const data = Object.keys(zhCN).map(key => ({
  'English': key,
  '中文': zhCN[key],
  'en-US': enUS[key]
}));

const ws = XLSX.utils.json_to_sheet(data);
const wb = XLSX.utils.book_new();
XLSX.utils.book_append_sheet(wb, ws, 'Translations');
XLSX.writeFile(wb, 'translations.xlsx');
```
