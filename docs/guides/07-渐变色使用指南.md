# ECharts 渐变色使用指南

## 问题背景

在 ECharts 中，文字和图形的颜色属性不能直接使用 CSS 的 `linear-gradient` 字符串。例如：

```javascript
// ❌ 这样不会生效
title: {
  textStyle: {
    color: 'linear-gradient(90deg, #ff0000 0%, #0000ff 100%)'
  }
}
```

## 解决方案

### 1. 使用转换工具函数

我们提供了 `colorConverter` 工具函数，可以自动将 CSS 渐变转换为 ECharts 格式：

```typescript
import { toEChartsColor, convertColorsInObject } from '@vario-echarts/smart-components';

// 方式 1: 单个颜色转换
const cssGradient = 'linear-gradient(90deg, #ff0000 0%, #0000ff 100%)';
const echartsColor = toEChartsColor(cssGradient);

// 方式 2: 批量转换对象中的颜色
const option = {
  title: {
    text: '标题',
    textStyle: {
      color: 'linear-gradient(90deg, #ff0000 0%, #0000ff 100%)'
    }
  }
};

const convertedOption = convertColorsInObject(option, ['title.textStyle.color']);
```

### 2. 转换结果示例

CSS 渐变：
```css
linear-gradient(90deg, #ff0000 0%, #0000ff 100%)
```

转换为 ECharts 格式：
```javascript
{
  type: 'linear',
  x: 0,
  y: 0,
  x2: 1,
  y2: 0,  // 从左到右
  colorStops: [
    { offset: 0, color: '#ff0000' },
    { offset: 1, color: '#0000ff' }
  ]
}
```

### 3. 在 LivePreview 中使用

更新 `LivePreview.vue` 来自动转换颜色：

```typescript
import { convertColorsInObject } from '@vario-echarts/smart-components';

// 更新图表时自动转换
function updateChart(config: Record<string, any>) {
  if (!chartInstance.value || !currentExample.value) return;
  
  // 转换所有可能包含颜色的属性
  const convertedConfig = convertColorsInObject(config, [
    'title.textStyle.color',
    'legend.textStyle.color',
    'xAxis.axisLabel.color',
    'yAxis.axisLabel.color',
    'series.itemStyle.color',
    'series.label.color'
  ]);
  
  // 合并并更新
  const mergedOption = { ...currentExample.value.baseOption, ...convertedConfig };
  chartInstance.value.setOption(mergedOption);
}
```

## 支持的渐变方向

| 角度 | 方向 | ECharts 坐标 |
|------|------|--------------|
| 0° | 向上 | (0,1) → (0,0) |
| 90° | 向右 | (0,0) → (1,0) |
| 180° | 向下 | (0,0) → (0,1) |
| 270° | 向左 | (1,0) → (0,0) |
| 45° | 右上 | 自动计算 |
| 135° | 右下 | 自动计算 |

## API 参考

### 类型定义

```typescript
// ECharts 线性渐变类型
interface EChartsLinearGradient {
  type: 'linear';
  x: number;   // 起点 x 坐标 (0-1)
  y: number;   // 起点 y 坐标 (0-1)
  x2: number;  // 终点 x 坐标 (0-1)
  y2: number;  // 终点 y 坐标 (0-1)
  colorStops: Array<{
    offset: number;  // 色标位置 (0-1)
    color: string;   // 颜色值
  }>;
}

// ECharts 径向渐变类型
interface EChartsRadialGradient {
  type: 'radial';
  x: number;   // 圆心 x 坐标 (0-1)
  y: number;   // 圆心 y 坐标 (0-1)
  r: number;   // 半径 (0-1)
  colorStops: Array<{
    offset: number;  // 色标位置 (0-1)
    color: string;   // 颜色值
  }>;
}

// ECharts 渐变联合类型
type EChartsGradient = EChartsLinearGradient | EChartsRadialGradient;
```

### 核心函数

#### `toEChartsColor(color)`

智能颜色转换函数，自动识别颜色类型并进行转换。

- **参数**: `color: string | undefined` - CSS 颜色或渐变字符串
- **返回**: `string | EChartsGradient | undefined` - ECharts 可用的颜色值

```typescript
import { toEChartsColor } from '@vario-echarts/smart-components';

// 普通颜色 - 直接返回
toEChartsColor('#FF0000');  // '#FF0000'
toEChartsColor('red');      // 'red'
toEChartsColor('rgb(255, 0, 0)');  // 'rgb(255, 0, 0)'

// 线性渐变 - 转换为 ECharts 对象
toEChartsColor('linear-gradient(90deg, #FF6B6B 0%, #4ECDC4 100%)');
// 返回: { type: 'linear', x: 0, y: 0.5, x2: 1, y2: 0.5, colorStops: [...] }

// 径向渐变 - 转换为 ECharts 对象
toEChartsColor('radial-gradient(circle, #FF6B6B 0%, #4ECDC4 100%)');
// 返回: { type: 'radial', x: 0.5, y: 0.5, r: 0.5, colorStops: [...] }

// undefined - 直接返回
toEChartsColor(undefined);  // undefined
```

#### `convertColorsInObject(obj, colorKeys)`

批量转换对象中的颜色属性，支持嵌套路径。

- **参数**: 
  - `obj: T` - 包含颜色属性的对象
  - `colorKeys: string[]` - 需要转换的属性路径数组（支持嵌套，使用 `.` 分隔）
- **返回**: `T` - 转换后的新对象（深拷贝）

```typescript
import { convertColorsInObject } from '@vario-echarts/smart-components';

const config = {
  title: {
    textStyle: {
      color: 'linear-gradient(90deg, #FF6B6B 0%, #4ECDC4 100%)'
    }
  },
  backgroundColor: 'linear-gradient(180deg, #1a1a2e 0%, #16213e 100%)'
};

// 支持嵌套路径
const converted = convertColorsInObject(config, [
  'backgroundColor',
  'title.textStyle.color'
]);
// 所有指定的颜色属性都会被转换为 ECharts 格式
```

### CSS 渐变转换函数

#### `cssLinearGradientToECharts(cssGradient)`

将 CSS 线性渐变转换为 ECharts 线性渐变对象。

- **参数**: `cssGradient: string` - CSS 线性渐变字符串
- **返回**: `EChartsLinearGradient | null` - ECharts 线性渐变对象

**支持的角度格式：**
- `to right`, `to left`, `to top`, `to bottom`
- `to top right`, `to bottom left` 等对角方向
- `0deg` - `360deg` 任意角度

```typescript
import { cssLinearGradientToECharts } from '@vario-echarts/smart-components';

// 使用方向关键字
cssLinearGradientToECharts('linear-gradient(to right, red 0%, blue 100%)');
// 返回: { type: 'linear', x: 0, y: 0.5, x2: 1, y2: 0.5, colorStops: [...] }

// 使用角度
cssLinearGradientToECharts('linear-gradient(45deg, #FF6B6B 0%, #4ECDC4 50%, #667eea 100%)');
// 返回: { type: 'linear', x: 0, y: 1, x2: 1, y2: 0, colorStops: [...] }

// 使用默认角度（180deg，从上到下）
cssLinearGradientToECharts('linear-gradient(#FF6B6B, #4ECDC4)');
```

**角度坐标映射表：**

| CSS 角度 | ECharts 坐标 (x, y, x2, y2) | 方向 |
|---------|---------------------------|------|
| 0deg / to top | 0.5, 1, 0.5, 0 | 下→上 |
| 90deg / to right | 0, 0.5, 1, 0.5 | 左→右 |
| 180deg / to bottom | 0.5, 0, 0.5, 1 | 上→下 |
| 270deg / to left | 1, 0.5, 0, 0.5 | 右→左 |
| 45deg / to top right | 0, 1, 1, 0 | 左下→右上 |
| 135deg / to bottom right | 0, 0, 1, 1 | 左上→右下 |

#### `cssRadialGradientToECharts(cssGradient)`

将 CSS 径向渐变转换为 ECharts 径向渐变对象。

- **参数**: `cssGradient: string` - CSS 径向渐变字符串
- **返回**: `EChartsRadialGradient | null` - ECharts 径向渐变对象

```typescript
import { cssRadialGradientToECharts } from '@vario-echarts/smart-components';

// 圆形渐变
cssRadialGradientToECharts('radial-gradient(circle, #FF6B6B 0%, #4ECDC4 100%)');
// 返回: { type: 'radial', x: 0.5, y: 0.5, r: 0.5, colorStops: [...] }

// 椭圆渐变（也会被转换，但 ECharts 只支持圆形）
cssRadialGradientToECharts('radial-gradient(ellipse, red 0%, blue 100%)');
```

#### `cssGradientToECharts(cssGradient)`

通用 CSS 渐变转换函数，自动识别线性或径向渐变。

- **参数**: `cssGradient: string` - CSS 渐变字符串
- **返回**: `EChartsGradient | null` - ECharts 渐变对象

```typescript
import { cssGradientToECharts } from '@vario-echarts/smart-components';

// 自动识别线性渐变
cssGradientToECharts('linear-gradient(90deg, red, blue)');

// 自动识别径向渐变
cssGradientToECharts('radial-gradient(circle, red, blue)');

// 无效输入返回 null
cssGradientToECharts('not a gradient');  // null
```

### 反向转换函数

#### `echartsGradientToCSS(gradient)`

将 ECharts 渐变对象转换为 CSS 渐变字符串（用于预览）。

- **参数**: `gradient: EChartsGradient` - ECharts 渐变对象
- **返回**: `string` - CSS 渐变字符串

```typescript
import { echartsGradientToCSS } from '@vario-echarts/smart-components';

// 线性渐变转 CSS
const linearGradient = {
  type: 'linear' as const,
  x: 0, y: 0.5, x2: 1, y2: 0.5,
  colorStops: [
    { offset: 0, color: '#FF6B6B' },
    { offset: 1, color: '#4ECDC4' }
  ]
};
echartsGradientToCSS(linearGradient);
// 返回: 'linear-gradient(90deg, #FF6B6B 0%, #4ECDC4 100%)'

// 径向渐变转 CSS
const radialGradient = {
  type: 'radial' as const,
  x: 0.5, y: 0.5, r: 0.5,
  colorStops: [
    { offset: 0, color: 'red' },
    { offset: 1, color: 'blue' }
  ]
};
echartsGradientToCSS(radialGradient);
// 返回: 'radial-gradient(circle, red 0%, blue 100%)'
```

### 辅助函数

#### `extractGradientDetails(input)`

从 CSS 渐变中提取详细信息。

- **参数**: `input: string` - CSS 渐变字符串
- **返回**: `{ direction?: string; colorStops: Array<{ color: string; offset: number }> } | null`

```typescript
import { extractGradientDetails } from '@vario-echarts/smart-components';

const details = extractGradientDetails('linear-gradient(90deg, red 0%, blue 50%, green 100%)');
// 返回:
// {
//   direction: '90deg',
//   colorStops: [
//     { color: 'red', offset: 0 },
//     { color: 'blue', offset: 0.5 },
//     { color: 'green', offset: 1 }
//   ]
// }
```

## 注意事项

1. ⚠️ **性能考虑**：大量渐变可能影响渲染性能，建议适度使用
2. ⚠️ **浏览器兼容性**：渐变在所有现代浏览器中都支持良好
3. ⚠️ **SVG 渲染器**：某些复杂渐变在 SVG 渲染器下可能表现不同
4. ✅ **推荐做法**：在配置提交前统一转换，而不是每次渲染时转换

## 完整示例

```typescript
import { toEChartsColor } from '@vario-echarts/smart-components';
import * as echarts from 'echarts';

// 创建图表
const chart = echarts.init(document.getElementById('chart'));

// 使用渐变
const option = {
  title: {
    text: '渐变标题示例',
    textStyle: {
      fontSize: 32,
      fontWeight: 'bold',
      color: toEChartsColor('linear-gradient(90deg, #FF6B6B 0%, #4ECDC4 100%)')
    }
  },
  series: [{
    type: 'pie',
    data: [
      { 
        value: 335, 
        name: '直接访问',
        itemStyle: {
          color: toEChartsColor('linear-gradient(180deg, #667eea 0%, #764ba2 100%)')
        }
      }
    ]
  }]
};

chart.setOption(option);
```
