# Generator 页面使用指南

## 概述

Generator 页面用于批量生成 ECharts 选项的 Vario Schema 文件，支持自定义输出格式、国际化、智能组件等功能。

## 主要功能

### 1. 选项选择

- **全选/清空**：快速选择或清空所有选项
- **单独选择**：勾选需要生成的配置项
- **支持的选项**：包括 63 个配置项，涵盖：
  - 布局与坐标系（title、legend、grid、xAxis、yAxis 等）
  - 系列图表（series-line、series-bar、series-pie 等 22 种）
  - 交互组件（tooltip、toolbox、dataZoom 等）
  - 全局样式和动画配置

### 2. 输出配置

#### 输出格式
- **ESM (.mjs)**：ES Module 格式，适用于现代前端项目
- **CommonJS (.cjs)**：CommonJS 格式，适用于 Node.js 项目
- **JSON (.json)**：纯 JSON 格式，便于其他工具处理

#### 输出模式
- **文件夹模式**：按层级组织，如 `output/series/line/index.mjs`
- **扁平文件**：所有文件在同一目录，如 `output/series-line.mjs`

### 3. Schema 语言

选择生成的 Schema 中 label、placeholder 等字段使用的语言：

- **简体中文**（默认）：所有字段名显示为中文
  - 例如：`label: "颜色"`、`placeholder: "字体大小"`
- **English**：所有字段名显示为英文
  - 例如：`label: "color"`、`placeholder: "fontSize"`

> **注意**：`_raw.desc` 字段始终保持 ECharts 官方的完整 HTML 描述（目前为中文），不受此设置影响。

### 4. 强制刷新数据

当启用"强制刷新数据"时，需要手动执行以下命令来更新本地缓存：

#### 更新 base 数据（必须）
```bash
pnpm cli fetch --force --save-to-base
```
这会从 ECharts 官方 API 获取最新的：
- `data/base/option.mjs` - 配置项元数据
- `data/base/type.mjs` - 类型树数据

#### 更新 options 描述数据（可选但推荐）
```bash
pnpm cli fetch --all --force --save-to-base
```
这会下载所有 48 个配置项的详细描述到 `data/base/options/zh-CN/` 或 `data/base/options/en-US/` 目录（取决于 locale），包括：
- 基础配置：title、legend、grid、tooltip 等
- 多级配置：dataZoom-slider、visualMap-continuous 等
- 系列配置：series-line、series-bar、series-pie 等

**执行后刷新页面**即可使用最新数据生成 Schema。

### 5. 国际化文件生成

启用"生成国际化文件"后，会自动生成多语言翻译文件：

- **输出路径**：`data/i18n/{语言代码}.json`
- **支持语言**：
  - zh-CN（简体中文）
  - en-US（English）
  - ja-JP（日本語）
  - ko-KR（한국어）

**国际化内容包括**：
- ✅ `placeholder`：字段占位符
- ✅ `title`：折叠项标题
- ✅ `_raw.label`：字段标签
- ❌ `_raw.desc`：**不翻译**（保持 ECharts 官方完整描述）

### 6. 智能组件

启用后，Schema 会使用项目中的智能组件：

- **SmartColorInput**：颜色选择器，支持纯色、渐变、透明色
- **SmartSizeInput**：尺寸输入，支持数值和百分比
- **SmartUnionInput**：联合输入，自动识别类型
- **SmartStyleSelect**：样式选择器，支持实线、虚线等

### 7. 下载压缩包

生成完成后，可以一键下载选中选项的 Schema 文件：

- **文件名格式**：`echarts-schemas-{语言}-{模式}-{日期}.zip`
  - 例如：`echarts-schemas-zh-CN-folder-2026-02-02.zip`
- **包含内容**：
  - 按照选择的输出模式组织的所有 Schema 文件
  - 自动应用选择的语言翻译

## 工作流程

### 推荐流程

1. **首次使用或需要更新数据时**：
   ```bash
   # 更新 base 数据
   pnpm cli fetch --force --save-to-base
   
   # 更新 options 描述
   pnpm cli fetch --all --force --save-to-base
   ```

2. **在 Generator 页面配置**：
   - 选择需要的选项
   - 设置 Schema 语言（中文/英文）
   - 选择输出格式和模式
   - 可选：启用国际化文件生成

3. **生成并下载**：
   - 点击"开始生成"
   - 等待生成完成
   - 点击"下载压缩包"获取所有文件

### 日常使用流程

如果数据已是最新，只需：
1. 勾选需要的选项
2. 点击"开始生成"
3. 下载压缩包

## 技术说明

### Schema 结构

生成的 Schema 包含以下关键字段：

```typescript
{
  type: "ElInput",           // 组件类型
  model: "title.text",       // 数据路径
  props: {
    placeholder: "文本"      // 占位符（已翻译）
  },
  _raw: {
    label: "文本",           // 字段标签（已翻译）
    desc: "<p>主标题文本...</p>"  // ECharts 官方完整描述（HTML 格式）
  }
}
```

### 数据来源

- **base 数据**：来自 `https://echarts.apache.org/zh/documents/option.js`
- **options 描述**：来自 `https://echarts.apache.org/zh/documents/option-parts/option.{key}.js`
- **翻译词表**：`data/translations.json`（自动生成）
- **国际化文件**：`data/i18n/{lang}.json`（自动生成）

### 缓存位置

- **base 数据**：`data/base/option.mjs` + `type.mjs`
- **options 描述**：`data/base/options/{locale}/*.mjs`（每种语言 48 个文件）
- **生成的 Schema**：`output/{选项名}/index.mjs`

## 常见问题

### Q: 为什么生成的 Schema 没有 desc 字段？

A: 需要先下载 options 描述数据：
```bash
pnpm cli fetch --all --save-to-base
```

### Q: 如何切换 Schema 的语言？

A: 在"Schema 语言"中选择"简体中文"或"English"，生成的 Schema 会自动应用对应语言的翻译。

### Q: desc 字段为什么始终是中文？

A: `_raw.desc` 来自 ECharts 官方文档，包含完整的 HTML 格式描述，目前官方只提供中文版本。该字段不应被翻译，因为它包含丰富的格式和链接信息。

### Q: 强制刷新数据的意义是什么？

A: 当 ECharts 发布新版本时，配置项和描述可能会更新。启用强制刷新可以忽略本地缓存，获取最新数据。

## 最佳实践

1. **定期更新数据**：建议每月执行一次 `pnpm cli fetch --all --force --save-to-base`
2. **按需生成**：不需要一次生成所有选项，选择实际使用的即可
3. **保存翻译词表**：`data/translations.json` 会自动累积翻译，建议提交到版本控制
4. **验证生成结果**：生成后点击"查看"按钮检查 Schema 是否正确
5. **使用压缩包**：批量下载比单个文件更方便管理
