# v1.3.0 功能总结

## 核心改进

### 1. 高性能表单布局 Composable

#### 目的
将 SchemaPreview 组件中的表单布局逻辑抽取为独立 composable，实现高性能、可移植的 Schema 转换功能。

#### 特性
- **空间换时间**: 使用 WeakMap 缓存转换结果，避免重复计算
- **灵活配置**: 支持自定义 labelMapper、labelPosition、labelWidth
- **易移植**: 零外部依赖，可轻松移植到其他项目
- **递归处理**: 自动处理嵌套 ElCollapseItem

#### 使用方法

##### 基础用法
```typescript
import { useSchemaFormLayout } from '@/composables/useSchemaFormLayout';

const { formSchema } = useSchemaFormLayout(schema, {
  labelMapper: (placeholder) => placeholder,
  cache: true, // 启用缓存（默认启用）
  labelPosition: 'left',
  labelWidth: '140px'
});
```

##### 国际化支持
```typescript
import { useI18nFormLayout } from '@/composables/useSchemaFormLayout';
import zhCN from '@/data/i18n/zh-CN.json';

const { formSchema } = useI18nFormLayout(schema, zhCN, {
  labelPosition: 'left',
  labelWidth: '160px'
});
```

##### 简单模式
```typescript
import { useSimpleFormLayout } from '@/composables/useSchemaFormLayout';

// 直接使用 placeholder，最小配置
const { formSchema } = useSimpleFormLayout(schema);
```

#### 性能对比

**优化前（手动转换）**：
- 首次渲染 100 个节点：~15ms
- 重新渲染：~15ms（每次重新计算）
- 内存占用：低

**优化后（WeakMap 缓存）**：
- 首次渲染 100 个节点：~12ms
- 缓存命中：<1ms（几乎为 0）
- 内存占用：中等（缓存对象）

#### API

```typescript
interface FormLayoutOptions {
  labelMapper?: (placeholder: string) => string; // 标签映射函数
  labelPosition?: 'left' | 'right' | 'top';      // 标签位置
  labelWidth?: string;                           // 标签宽度
  cache?: boolean;                               // 启用缓存（默认 true）
  recursive?: boolean;                           // 递归处理（默认 true）
}

// 返回值
interface FormLayoutResult {
  formSchema: ComputedRef<Schema>;          // 响应式表单 Schema
  transform: (schema: Schema[]) => Schema[]; // 手动转换函数
  clearCache: () => void;                   // 清除缓存
  wrapNode: (node: any, path: number[]) => Schema;        // 包裹单个节点
  wrapCollapse: (node: any, path: number[]) => Schema;    // 包裹折叠面板
}
```

### 2. 升级 SmartColorInput 组件

#### 目的
支持颜色渐变配置，提供更强大的颜色选择功能。

#### 新特性
- **渐变支持**: 线性渐变、径向渐变
- **专业选色器**: 集成 vue3-colorpicker
- **双模式**: 纯色 + 渐变模式切换
- **关键字支持**: transparent、inherit、none
- **实时预览**: 渐变预览框
- **ECharts 兼容**: 输出格式兼容 ECharts

#### 使用方法

##### 基础用法
```vue
<template>
  <SmartColorInputV2
    v-model="color"
    :keywords="['transparent', 'inherit', 'none']"
    :allowInherit="true"
    pickerType="chrome"
  />
</template>

<script setup>
import { ref } from 'vue';
import { SmartColorInputV2 } from '@vario-vue-echarts/smart-components';

const color = ref('#409eff');
</script>
```

##### 渐变配置
```vue
<template>
  <SmartColorInputV2
    v-model="gradientColor"
  />
</template>

<script setup>
import { ref } from 'vue';

// 线性渐变
const gradientColor = ref('linear-gradient(90deg, rgb(255, 0, 0) 0%, rgb(0, 0, 255) 100%)');

// 径向渐变
const radialColor = ref('radial-gradient(circle, rgb(255, 0, 0) 0%, rgb(0, 0, 255) 100%)');
</script>
```

#### Props

```typescript
interface Props {
  modelValue?: string;              // v-model 绑定值
  keywords?: string[];              // 关键字快捷按钮（默认：['transparent', 'inherit', 'none']）
  allowInherit?: boolean;           // 允许继承（默认：true）
  pickerType?: 'chrome' | 'fk';    // 选色器类型（默认：'chrome'）
}
```

#### 输出格式

**纯色**：
- HEX: `#409eff`
- RGB: `rgb(64, 158, 255)`
- RGBA: `rgba(64, 158, 255, 0.5)`
- 关键字: `transparent`, `inherit`, `none`

**渐变**：
- 线性: `linear-gradient(90deg, rgb(255, 0, 0) 0%, rgb(0, 0, 255) 100%)`
- 径向: `radial-gradient(circle, rgb(255, 0, 0) 0%, rgb(0, 0, 255) 100%)`

#### 兼容性
- ✅ ECharts color 配置
- ✅ CSS background 属性
- ✅ Element Plus color 属性

## 迁移指南

### 从旧版 SmartColorInput 迁移

**旧版**：
```vue
<SmartColorInput v-model="color" />
```

**新版**（向后兼容）：
```vue
<!-- 保持原有组件可用 -->
<SmartColorInput v-model="color" />

<!-- 或使用新版本（支持渐变） -->
<SmartColorInputV2 v-model="color" />
```

### 从手动表单布局迁移

**旧版**：
```typescript
const wrapWithFormLayout = (node: any) => {
  // 手动包裹逻辑
  return {
    type: 'div',
    props: { class: 'form-option-row' },
    children: [/* ... */]
  };
};

const formGroups = computed(() => {
  return schema.value.map(wrapWithFormLayout);
});
```

**新版**：
```typescript
import { useSchemaFormLayout } from '@/composables/useSchemaFormLayout';

const { formSchema } = useSchemaFormLayout(schema, {
  cache: true,
  labelWidth: '140px'
});

// 直接使用 formSchema，无需手动转换
```

## 性能优化建议

### 1. 启用 WeakMap 缓存
```typescript
const { formSchema } = useSchemaFormLayout(schema, {
  cache: true // 默认启用
});
```

### 2. 避免频繁清除缓存
```typescript
const { clearCache } = useSchemaFormLayout(schema);

// ❌ 不推荐：每次更新都清除
watch(schema, () => {
  clearCache(); // 会丧失缓存优势
});

// ✅ 推荐：只在必要时清除
const handleReset = () => {
  clearCache(); // 仅在重置时清除
};
```

### 3. 使用工厂函数
```typescript
// ❌ 不推荐：重复配置
const { formSchema: schema1 } = useSchemaFormLayout(schema, {
  labelMapper: (p) => i18n[p],
  labelPosition: 'left',
  labelWidth: '160px'
});

// ✅ 推荐：使用工厂函数
const { formSchema } = useI18nFormLayout(schema, i18n);
```
