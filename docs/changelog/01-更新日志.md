# 更新日志

## [1.3.0] - 2024-02-XX

### ✨ 新增功能

#### 高性能表单布局 Composable
- **useSchemaFormLayout**：抽取表单布局逻辑为独立 composable
- **WeakMap 缓存**：空间换时间，缓存命中性能提升 15 倍以上
- **灵活配置**：支持自定义 labelMapper、labelPosition、labelWidth
- **易移植**：零外部依赖，纯函数式设计
- **递归处理**：自动处理嵌套 ElCollapseItem

**三个工厂函数**：
- `useSchemaFormLayout` - 标准用法（完全自定义）
- `useI18nFormLayout` - 国际化标签映射
- `useSimpleFormLayout` - 零配置快速使用

**API**：
```typescript
const { formSchema, transform, clearCache, wrapNode, wrapCollapse } = useSchemaFormLayout(schema, {
  labelMapper: (placeholder) => placeholder,
  labelPosition: 'left',
  labelWidth: '140px',
  cache: true,
  recursive: true
});
```

#### SmartColorInputV2 组件（支持渐变）
- **渐变支持**：线性渐变、径向渐变
- **专业选色器**：集成 vue3-colorpicker
- **双模式切换**：纯色 ↔ 渐变无缝切换
- **关键字快捷按钮**：transparent、inherit、none
- **实时预览**：渐变预览框 + 渐变信息
- **ECharts 兼容**：输出格式兼容 ECharts color 配置
- **自动应用**：CLI 生成的 Schema 自动使用新组件

**Props**：
```typescript
interface Props {
  modelValue?: string;
  keywords?: string[];           // 默认：['transparent', 'inherit', 'none']
  allowInherit?: boolean;        // 默认：true
  pickerType?: 'chrome' | 'fk'; // 默认：'chrome'
}
```

**支持格式**：
- 纯色：`#409eff`, `rgb(64, 158, 255)`, `rgba(64, 158, 255, 0.5)`
- 渐变：`linear-gradient(90deg, rgb(255, 0, 0) 0%, rgb(0, 0, 255) 100%)`

#### CLI 输出模式选项
- **--output-mode folder**（默认）：文件夹层级结构（`output/series/line/index.mjs`）
- **--output-mode flat**：扁平文件名（`output/series-line.mjs`）

**使用场景**：
- `folder` - 大型项目，支持 tree-shaking
- `flat` - 小型项目，文件列表清晰

**示例**：
```bash
# 文件夹模式（默认）
pnpm cli convert --output-mode folder

# 扁平模式
pnpm cli convert --output-mode flat
```

#### CLI 国际化文件生成
- **--i18n**：自动生成多语言国际化文件
- **--i18n-langs**：指定语言列表（默认：zh-CN, en-US）

**支持语言**：
- `zh-CN` - 简体中文（DeepSeek 翻译）
- `en-US` - 英文（驼峰转空格）
- `ja-JP` - 日文（预留，使用英文）
- `ko-KR` - 韩文（预留，使用英文）

**示例**：
```bash
# 生成中英文国际化文件
pnpm cli convert --translate --i18n

# 自定义语言
pnpm cli convert --translate --i18n --i18n-langs zh-CN en-US ja-JP ko-KR

# 输出：
# data/i18n/zh-CN.json
# data/i18n/en-US.json
# data/i18n/ja-JP.json
# data/i18n/ko-KR.json
```

### 🎯 技术细节

#### Composable 性能对比

| 方案 | 首次渲染 | 缓存命中 | 内存占用 |
|------|---------|---------|---------|
| 手动转换（每次重新计算） | ~15ms | ~15ms | 低 |
| WeakMap 缓存（cache: true） | ~12ms | <1ms | 中 |

**结论**：
- 首次渲染性能相近（~12-15ms）
- 缓存命中性能提升 **15 倍以上**（15ms → <1ms）
- 内存占用略有增加但可接受

#### SmartColorInputV2 特性

- **模式自动检测**：根据 modelValue 自动切换纯色/渐变
- **类型断言优化**：修复 TypeScript 类型推断问题
- **CSS 变量支持**：主题色、边框色等可自定义
- **渐变格式转换**：vue3-colorpicker 格式 → ECharts 格式

### 🔄 迁移指南

#### 从手动布局迁移到 Composable

**旧版**：

```typescript
import { useSchemaFormLayout } from '@/composables/useSchemaFormLayout';

const { wrapCollapse } = useSchemaFormLayout([], {

  cache: true
});

const wrappedNode = wrapCollapse(node, 'group-0');
```

## [1.1.0] - 2024-01-XX

### ✨ 新增功能

#### 自动翻译系统
- **集成 DeepSeek API**：实现英文字段名到中文标签的自动翻译
- **词表管理**：生成并维护 `data/translations.json` 中英词表（692 条）
- **CLI 支持**：
  - 新增 `--translate` 选项启用自动翻译
  - 新增 `--api-key` 选项自定义 API 密钥
- **批量翻译**：每批处理 50 个字段，优化 API 调用效率
- **增量更新**：只翻译新字段，已有翻译保留缓存
- **错误容错**：API 失败时使用驼峰命名 fallback

### 🔧 优化改进

#### SchemaPreview 组件简化
- **删除硬编码**：移除 90+ 行的手动字段映射代码
- **自动标签**：直接使用 Schema 中的翻译后 placeholder
- **简化逻辑**：去除复杂的 `getFieldLabel()` 函数

#### CLI 转换流程
- **两遍扫描**：
  1. 第一遍收集所有字段
  2. 调用 API 批量翻译
  3. 第二遍生成 Schema 并应用翻译
- **进度显示**：显示翻译进度和词表统计

### 📚 文档更新

## 版本号说明

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/) 规范：

- **主版本号**（MAJOR）：不兼容的 API 修改
- **次版本号**（MINOR）：向下兼容的功能性新增
- **修订号**（PATCH）：向下兼容的问题修正
