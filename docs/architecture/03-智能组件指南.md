# Smart Components 智能组件指南

## `_smart` 元数据说明

### 什么是 `_smart`？

`_smart` 是 SchemaGenerator 生成的元数据字段，存储在每个 Schema 节点中，用于描述该字段的类型分析结果。

### `_smart` 数据结构

```typescript
{
  _smart: {
    rawTypes: string[];          // 原始类型列表，如 ["string", "number"]
    category: FieldCategory;     // 字段类别：color | size | position | style | number | string | boolean | generic
    specialKeywords: string[];   // 特殊关键字，如 ["inherit", "auto", "transparent"]
    allowCustom: boolean;        // 是否允许自定义输入
    propPattern: PropPattern;    // 属性模式：generic | color-suffix | border | shadow | text | font | width | height | position | type-suffix
    enumOptions?: string[];      // 枚举选项（如果是枚举类型）
  }
}
```

### `_smart` 的作用

#### 1. **智能组件选择**

根据 `category` 和 `rawTypes`，SchemaGenerator 自动选择最合适的智能组件：

| Category | 智能组件 | 用途 |
|---------|---------|------|
| `color` | `SmartColorInput` | 颜色输入，支持关键字（inherit、transparent等） |
| `size` | `SmartSizeInput` | 尺寸输入，支持数字、百分比、auto关键字 |
| `position` | `SmartPositionInput` | 定位输入，支持left/right/center/top/bottom |
| `style` | `SmartStyleSelect` | 样式选择，支持solid/dashed/dotted |
| `opacity` | `SmartOpacityInput` | 透明度输入，0-1范围滑块 |
| `union` | `SmartUnionInput` | 联合类型输入，可切换string/number类型 |
| `number` (with keywords) | `SmartNumberInput` | 数字输入，支持特殊关键字 |

#### 2. **组件 Props 配置**

`_smart.specialKeywords` 和 `_smart.allowCustom` 被用来配置智能组件的行为：

```typescript
// 示例：颜色字段
{
  type: "SmartColorInput",
  props: {
    keywords: ["inherit", "transparent", "none"],  // 来自 _smart.specialKeywords
    allowInherit: true                             // 根据 keywords 判断
  }
}

// 示例：尺寸字段
{
  type: "SmartSizeInput",
  props: {
    allowPercentage: true,                         // 根据 category 判断
    keywords: ["auto"]                             // 来自 _smart.specialKeywords
  }
}
```

#### 3. **类型验证和转换**

在运行时，`_smart.rawTypes` 可用于：
- 输入验证（确保用户输入符合原始类型定义）
- 类型转换（如字符串"100"转换为数字100）
- 智能提示（根据类型提供合适的输入建议）

#### 4. **文档生成**

`_smart` 元数据可用于自动生成：
- 字段说明文档
- 类型提示信息
- 配置示例

## Smart Components 使用指南

### 已实现的智能组件

#### 1. SmartColorInput - 智能颜色输入

**特性：**
- 原生颜色选择器 + 文本输入
- 支持关键字快捷按钮（inherit、transparent、none）
- 自动识别颜色值和关键字模式

**Props：**
```typescript
{
  modelValue?: string;
  keywords?: string[];        // 默认 ['inherit', 'none', 'transparent']
  allowInherit?: boolean;     // 默认 true
}
```

**使用示例：**
```typescript
{
  type: "SmartColorInput",
  model: "title.textStyle.color",
  props: {
    keywords: ["inherit", "transparent"],
    allowInherit: true
  }
}
```

#### 2. SmartSizeInput - 智能尺寸输入

**特性：**
- 数字输入 + 单位选择（px、%）
- 支持 auto 关键字
- 自动格式化百分比值

**Props：**
```typescript
{
  modelValue?: string | number;
  allowPercentage?: boolean;  // 默认 true
  keywords?: string[];        // 默认 ['auto']
}
```

#### 3. SmartPositionInput - 智能定位输入

**特性：**
- 支持预设位置关键字（left、right、center、top、bottom）
- 支持数字 + 百分比
- 可视化位置选择（如果实现）

**Props：**
```typescript
{
  modelValue?: string | number;
  keywords?: string[];        // 默认 ['left', 'right', 'center', 'top', 'bottom', 'auto']
  allowPercentage?: boolean;  // 默认 true
}
```

#### 4. SmartStyleSelect - 智能样式选择

**特性：**
- 下拉选择样式类型（solid、dashed、dotted）
- 支持自定义虚线数组
- 可视化样式预览

**Props：**
```typescript
{
  modelValue?: string | number | number[];
  options?: string[];         // 默认 ['solid', 'dashed', 'dotted']
  allowCustom?: boolean;      // 默认 true
}
```

#### 5. SmartUnionInput - 智能联合类型输入

**特性：**
- 类型切换器（string ↔ number）
- 根据当前类型显示对应输入控件
- 自动类型转换

**Props：**
```typescript
{
  modelValue?: string | number;
  types?: string[];           // 如 ['string', 'number']
  defaultType?: string;       // 默认类型
  specialKeywords?: string[]; // 字符串模式下的关键字
}
```

#### 6. SmartNumberInput - 智能数字输入

**特性：**
- 数字输入 + 关键字支持
- 可选步进器
- 范围限制

**Props：**
```typescript
{
  modelValue?: number | string;
  keywords?: string[];        // 如 ['auto', 'inherit']
  min?: number;
  max?: number;
  step?: number;
}
```

#### 7. SmartOpacityInput - 智能透明度输入

**特性：**
- 0-1 范围滑块
- 实时预览
- 支持 inherit 关键字

**Props：**
```typescript
{
  modelValue?: number | string;
  min?: number;               // 默认 0
  max?: number;               // 默认 1
  step?: number;              // 默认 0.1
  keywords?: string[];        // 默认 ['inherit']
}
```

## 在 Studio 中使用 Smart Components

### 1. 注册组件（已完成）

在 `apps/studio/src/main.ts` 中：

```typescript
import SmartComponents from '@vario-echarts/smart-components';

app.use(SmartComponents);
```

### 2. 在 Schema 中使用

SchemaGenerator 会自动生成包含智能组件的 Schema：

```typescript
// 自动生成的 Schema
[
  {
    type: "SmartColorInput",    // ← 智能组件
    model: "title.textStyle.color",
    props: {
      keywords: ["inherit", "transparent"],
      allowInherit: true
    },
    _smart: {                    // ← 元数据
      rawTypes: ["color"],
      category: "color",
      specialKeywords: ["inherit", "transparent"],
      allowCustom: false
    }
  }
]
```

### 3. useVario 自动识别

`useVario` 会自动识别已注册的智能组件并渲染：

```vue
<script setup>
import { useVario } from '@variojs/vue';

const schema = [/* ... */];
const { vnode, state } = useVario(schema);
</script>

<template>
  <component :is="vnode" />
  <!-- 自动渲染 SmartColorInput、SmartSizeInput 等智能组件 -->
</template>
```

## 常见问题

### Q1: 为什么生成的 Schema 中有些字段还是 ElInput 而不是 Smart 组件？

**A:** 可能原因：
1. 该字段的类型分析结果不符合智能组件的条件（如纯 string 类型，无特殊关键字）
2. SchemaGenerator 的 `useSmartComponents` 选项未开启（默认开启）

### Q2: `_smart` 数据不完整是什么意思？

**A:** 部分字段的 `_smart` 可能缺少某些属性（如 `enumOptions`），这是正常的：
- `enumOptions` 仅在 `category === 'style'` 时存在
- 不同类型的字段有不同的元数据字段集合

### Q3: 能否手动修改 `_smart` 数据？

**A:** 可以，但不推荐：
- `_smart` 是 SchemaGenerator 自动生成的
- 手动修改可能导致与实际类型不一致
- 建议修改 TypeAnalyzer 的分析逻辑来调整生成结果

### Q4: Smart 组件与普通 Element Plus 组件的区别？

**A:** 
- **普通组件**（ElInput、ElInputNumber）：基础输入控件
- **智能组件**（SmartColorInput、SmartSizeInput）：增强型控件，支持多种输入模式和类型转换
- 智能组件通常包装了多个普通组件，提供更丰富的交互

## 总结

`_smart` 元数据是连接**类型分析**和**智能组件**的桥梁：

1. **类型分析器（TypeAnalyzer）** → 生成 `_smart` 元数据
2. **Schema 生成器（SchemaGenerator）** → 使用 `_smart` 选择智能组件
3. **智能组件（Smart Components）** → 接收 props 并提供增强交互
4. **useVario** → 渲染智能组件到页面

通过这套机制，实现了从 ECharts 类型定义到可视化配置表单的自动化转换。
